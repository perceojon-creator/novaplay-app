### Novedades v1.9.0
- ⚡ **YouTube Shorts nativo:** deslizamiento vertical continuo con bucle infinito, gestos táctiles, Me Gusta, comentarios y suscripciones.
- 🎨 **Estilo YouTube Vanced:** paleta AMOLED #0F0F0F, acento rojo #FF0033, tipografía sans-serif-medium y nuevas transiciones.
- 📱 **Barra de navegación inferior:** Inicio, Shorts, Suscripciones y Tú.
- 📺 **Android TV / Leanback:** HUD en pantalla para control remoto D-Pad y soporte completo de televisores.
